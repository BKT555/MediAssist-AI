# MediAssist AI: A Multimodal Clinical Decision-Support Assistant

## Project Description
MediAssist AI is a multimodal AI system designed to support clinicians during preliminary triage and diagnosis by combining conversational NLP for symptom extraction, computer vision for medical image classification with Grad-CAM explainability, and a decision-fusion risk scoring engine.
