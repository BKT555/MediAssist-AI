# MediAssist AI: A Multimodal Clinical Decision-Support Assistant

## Project Overview
MediAssist AI is a clinical decision-support system designed for preliminary triage and diagnosis by integrating conversational NLP, medical image analysis, and clinical risk-scoring models.
